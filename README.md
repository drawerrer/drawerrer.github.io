# Archive Collection (Writings Cabinet)

A personal archive website designed with a skeuomorphic aesthetic, featuring a virtual wooden cabinet interface for managing writings, photography, and community interactions.

## Features

- **Skeuomorphic Design**: Realistic wooden drawer interactions, tilt effects, and paper textures.
- **Dynamic Content**:
    - **Writings**: Essays displayed as collectible ticket strips / stamps inside a drawer.
    - **Photography**: Photo collections organized in folders.
    - **Community**: Guestbook system.
- **Admin Dashboard**: Client-side content management (localStorage based) for creating posts and managing comments.
- **Responsive**: Fully responsive design for Desktop and Mobile.
- **Dark Mode**: Integrated dark/light mode toggle.

## Tech Stack

- **HTML5**
- **Tailwind CSS** (via CDN for development/demo)
- **Vanilla JavaScript** (No framework dependency)
- **LocalStorage** (for data persistence)

## Structure

- `index.html`: Main entry point (Cabinet View).
- `writings.html`: Essay collection (Drawer & Reading View).
- `photography.html`: Photo gallery.
- `community.html`: Guestbook.
- `admin.html`: Admin dashboard for content creation.

## Deployment

This is a static website. It can be hosted on:
- GitHub Pages
- Vercel
- Netlify

Simply upload the files to your repository and enable the static site serving feature.
